02 — About

Our journey so far

We started with a simple shared curiosity: how do websites actually work? That question took us from our first <h1> tags to building complete, responsive layouts with CSS Grid and Bootstrap — as a team.

Today we split the work the way real teams do: one person leads, one designs and presents, one builds — and we review each other's code on GitHub.

Our goals

  • Contribute to open-source projects
  • Ship every project live on GitHub Pages or Vercel
