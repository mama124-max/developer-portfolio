**Built with:** semantic HTML5, custom CSS3 (Grid/Flexbox), Bootstrap 5, vanilla JavaScript.

## Files
```
index.html        – all sections (Home, Team, About & Skills, Projects, GitHub, Contact)
css/style.css     – custom styles
js/script.js      – navbar, scroll animations, GitHub repos, contact form validation
images/           – team photos and project previews
```

## Deploy
**GitHub Pages:** create a repo, upload these files to the root, then Settings → Pages → Branch: `main` / root → Save.

**Vercel:** push to GitHub, then "Add New Project" on vercel.com and import the repo. No build command needed.

## Customise
- In `js/script.js`, set `GITHUB_USERNAME` to load your live repositories.
- Replace the placeholder email, WhatsApp, LinkedIn, GitHub and project links in `index.html`.
